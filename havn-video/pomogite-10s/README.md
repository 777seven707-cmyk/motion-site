# HAVN · «Помогите нам» — 10 секунд

Самый короткий формат (1080×1920, 60 fps, 10 с): только просьба помочь.
Мягкая анимация (движок из `pomogite-nam-myagko`), одна сцена — камера
плавно едет вниз по столу: «пожалуйста, ПОМОГИТЕ НАМ» → «скопируйте ссылку»
→ копия улетает самолётиком к человечку под тучкой, он загорается →
«спасибо» и ссылка.

- `release/havn_pomogite_10s.mp4` — видео с музыкой и звуками, без голоса
- `release/cover.png` — кадр для обложки
- `VOICEOVER.md` — текст для ElevenLabs, описание и закреплённый комментарий

Исходники: `engine.js`, `scene.js`, `tools/render.mjs`, `tools/audio.py`,
`tools/mix_voice.py`.
