# HAVN · «Помогите нам»

Короткий TikTok-ролик (1080×1920, 60 fps, 21 с) в стиле «Всё нормально» и
«Челюсти»: тушь от руки + бумажный коллаж. Просьба о помощи самому HAVN:
мы помогаем людям — помогите и нам стать популярными — скопируйте ссылку,
чтобы больше людей не оставались одни.

- `release/havn_pomogite_nam.mp4` — видео с музыкой и звуками, без голоса
- `release/cover.png` — кадр для обложки
- `VOICEOVER.md` — текст для ElevenLabs, таймкоды, описание и закреплённый комментарий
- `STORYBOARD.md` — раскадровка

Исходники: `engine.js` (общий движок бумаги и туши), `scene.js` (этот ролик),
`tools/render.mjs`, `tools/audio.py`, `tools/mix_voice.py` (таблицу фраз
нужно выставить под присланный дубль).
