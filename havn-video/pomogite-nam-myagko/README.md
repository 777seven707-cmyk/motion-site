# HAVN · «Помогите нам» — мягкая версия

Вариант ролика «Помогите нам» (1080×1920, 60 fps, 32 с) с плавной анимацией
вместо стоп-моушена: бумага не падает и не шлёпается, а мягко всплывает и
оседает, тушь не «кипит», а медленно дышит, камера переезжает дольше и
спокойнее. Начинается с жалости: один серый человечек ночью под тучкой,
рядом телефон — «нет новых сообщений».

- `release/havn_pomogite_nam_myagko.mp4` — видео с музыкой и звуками, без голоса
- `release/cover.png` — кадр для обложки
- `VOICEOVER.md` — текст для ElevenLabs, таймкоды, описание и закреплённый комментарий
- `STORYBOARD.md` — раскадровка

Исходники: `engine.js` (мягкий вариант общего движка: `step12` без шагов,
плавные `drop`/`jit`, сглаженный шум вместо «кипения» туши), `scene.js`,
`tools/render.mjs`, `tools/audio.py`, `tools/mix_voice.py` (таблицу фраз
нужно выставить под присланный дубль).
