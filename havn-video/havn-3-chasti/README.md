# HAVN · серия «три части»

Три вертикальных ролика (1080×1920, 60 fps) в мягком скетчбук-стиле —
тушь + бумага, плавная анимация, как «Помогите нам» (мягко). Каждая часть
начинается с трудного момента и показывает, что для него есть в HAVN.
Все инструменты — настоящие, с сайта.

| Часть | Файл | Длина | О чём |
|---|---|---|---|
| 1 | `release/havn_chast1_kogda_nakryvaet.mp4` | 21,5 с | «Подышим вместе», «Вернуться в комнату» 5-4-3-2-1, «Отдайте тревогу небу» |
| 2 | `release/havn_chast2_kogda_sil_net.mp4` | 20 с | «Маленькие шаги» («Сколько сейчас сил?» → «Сделано» → «Это считается.»), «Маленькие хорошие вещи» |
| 3 | `release/havn_chast3_kogda_odinoko.mp4` | 24,5 с | питомец («Немного компании»), гайды «Когда дело в людях», кнопка «Мне плохо прямо сейчас», просьба поделиться видео |

- `release/coverN.png` — обложки
- `VOICEOVER.md` — тексты для ElevenLabs, описания и хэштеги
- `STORYBOARD.md` — раскадровка

Исходники: `engine.js` (мягкий движок), `lib.js` (общие куски серии),
`part1.js`–`part3.js`, `index.html?part=N`.
Рендер: `PART=N node tools/render.mjs video 4`, звук: `python3 tools/audio.py N`.
