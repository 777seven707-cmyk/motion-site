# HAVN · «Маленький призрак»

История на 95 секунд (1920×1080, 60 fps) в стиле по мотивам Kurzgesagt:
Мира с апатией и депрессией, комната-остров в космосе без цвета, маленький
призрак с фонариком, который светит на одно маленькое дело — и мостик из
сделанных дел к подруге и специалисту.

- `release/havn_prizrak.mp4` — видео с музыкой и звуками, без голоса
- `VOICEOVER.md` — текст для ElevenLabs, таймкоды, описание
- `STORYBOARD.md` — раскадровка и отброшенные варианты

Исходники: `scene.js` (вся анимация, векторная графика на Canvas 2D),
`tools/render.mjs` (рендер), `tools/audio.py` (музыка и звуки),
`tools/mix_voice.py` (сведение голоса).
