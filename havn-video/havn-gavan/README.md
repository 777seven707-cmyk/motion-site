# HAVN · «Гавань» — обзор сайта

Вертикальный ролик на минуту для TikTok в стиле «Устал от всего?»: тушь от
руки, бумажный коллаж, кинетическая типографика. *Havn* по-датски значит
«гавань»: бумажный кораблик выходит из шторма слов, проходит мимо всего, что
есть на сайте, и на рассвете заходит в гавань.

- `release/havn_gavan.mp4` — 1080×1920, 60 fps, 63,5 с, H.264 + AAC, музыка
  и SFX без голоса
- `release/cover.png` — кадр для обложки
- `VOICEOVER.md` — текст для ElevenLabs, таймкоды, описание к публикации
- `STORYBOARD.md` — раскадровка и отброшенные варианты

## Исходники

- `engine.js` — общий движок: бумага с фактурой и тенями, тушь с «кипением»,
  буквы-вырезки, камера по ключам, motion blur на быстрых проездах.
- `scene.js` — этот ролик: таймлайн `T`, расположение сцен `SC`, по
  функции на сцену, список звуковых событий.
- `tools/render.mjs` — рендер в headless Chromium → ffmpeg
  (`node tools/render.mjs video 4`, `stills 9.6 18.4`).
- `tools/audio.py` — музыка и SFX по `out/sfx.json`.
- `tools/mix_voice.py` — режет дубль ElevenLabs на фразы и ставит их под
  кадры, приглушает музыку под голосом, −14 LUFS.
