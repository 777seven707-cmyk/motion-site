# Город красок — 3D

Серый город под хмурой тучей. Мячик с глазами прыгает по улицам и крышам, и
каждое приземление разносит волну цвета: дома, окна, деревья, машины, фонтан,
воздушные шары. В конце мячик прыгает с башни и «бупает» тучу в нос — она
улыбается, появляется радуга, город и небо окрашиваются целиком. Музыка
тоже «окрашивается»: с каждым прыжком в ней появляется новый инструмент.

- `release/gorod_krasok_1080p60.mp4` — 1920×1080, 60 fps, 45 с, H.264 + AAC
- `STORYBOARD.md` — раскадровка и отброшенные варианты

## Как устроено

- `city.js` — вся сцена на Three.js: маршрут мячика (`PATH`), город,
  камера (планы `SHOTS` + пружина для инерции), туча, радуга, титры.
  Момент, когда волна цвета доходит до каждой точки города, и кляксы
  заранее «запекаются» в текстуры, а шейдер только сравнивает их со
  временем: так кадр считается в 2 раза быстрее.
- `tools/render.mjs` — покадровый рендер в headless Chromium (WebGL через
  SwiftShader) → ffmpeg. `node tools/render.mjs video 1920 1080 60 2`;
  `stills 960 540 5.1 20.5` — отдельные кадры для проверки.
- `tools/audio.py` — музыка и звуки, синтез в numpy по списку событий
  из сцены (`out/sfx.json`).

В браузере `index.html` (через любой статический сервер, после `npm i`)
играет в реальном времени; `?t=30` показывает один кадр.
