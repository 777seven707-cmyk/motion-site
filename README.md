# Broken Vinyl — атлас музыкальных жанров

Сайт про музыку: вначале крутится виниловая пластинка, потом трескается и разлетается на осколки, и через «дыру» проявляется сам сайт — 15 жанров и по 6 самых известных исполнителей в каждом.

## Запуск

Сборка не нужна. Откройте `index.html` в браузере или поднимите любой статический сервер:

```
python3 -m http.server 8000
```

## Что внутри

| Файл | Назначение |
| --- | --- |
| `data.js` | жанры, цвета, исполнители и их хиты; поля `fx` и `anim` задают стиль перехода и анимации заголовка |
| `record.js` | пластинка, трещины и осколки (одна геометрия для линий и для `clip-path`) |
| `intro.js` | сценарий заставки |
| `transitions.js` | 11 стилей переходов: circle, curtains, blinds, diagonal, pixels, slide, glitch, spin, teeth, flip, iris |
| `audio.js` | звук, синтезируется через Web Audio (включается кнопкой) |
| `app.js` | главная, поиск, страницы жанров, роутинг (`#/genre/rock`) |

Управление: ← → листают жанры, Esc возвращает к списку. Заставку можно пропустить, а клик по пластинке ускоряет разлом.
